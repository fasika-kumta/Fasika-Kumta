### 💳 Credit Default Prediction — Bachelor's Thesis

A comparative study of machine-learning and statistical models for credit-default prediction, using the UCI Default of Credit Card Clients dataset.

- Compared **Logistic Regression, Random Forest, and XGBoost**.
- Worked with a dataset containing 30,000 credit-card clients.
- Used Python for data preparation, model development, and evaluation.
- Compared models using accuracy, precision, recall, F1-score, and ROC-AUC.
- Examined predictive performance and model interpretability in financial decision-making.
